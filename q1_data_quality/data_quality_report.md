## 5. 可疑现象

1. **数量极值正负对称**：quantity 最小 -80,995.00，最大 80,995.00，而中位数只有 3.00、99% 分位为 100.00。
2. **负数量不等于 C 发票**：负数量共 22,950 行，其中 C 发票 19,493 行；另有 3,457 行不是 C 发票，其中单价为 0 的 3,457 行、缺客户号的 3,457 行。
3. **C 发票大多找不到同数量的原始购买**：有客户号的 C 行（去重后）17,586 行中，能在之前找到同客户、同商品、同数量购买的只有 6,346 行（36.09%）。
4. **负单价**：5 行，最小 -53,594.36；其中属于 A 发票的 5 行。
5. **零单价**：6,202 行，其中缺客户号 6,131 行、缺描述 4,382 行。
6. **缺失描述全部伴随零单价和缺客户号**：缺描述 4,382 行，其中单价为 0 的 4,382 行、缺客户号的 4,382 行。
7. **描述的大小写写法不统一**：普通商品销售行中全大写描述占 99.70%；全表另有 732 行全小写、5,235 行大小写混合。
8. **客户号缺失**：243,007 行（22.77%），金额净值占全表 13.68%。
9. **同一商品单价差异大**：90.10% 的商品不止一个单价；两类都卖过的 4,096 个商品中，匿名记录单价是有客户号记录的 1.99 倍（中位数）。
10. **离群高价**：799 行普通商品销售的单价超过该商品单价中位数的 10 倍；另有 18 行单价在 0 到 0.01 之间。
11. **完全重复行**：8 列全部相同的多余行共 34,335 行。 文件第 525,463 行处日期从 2010-12-09 20:01:00 回退到 2010-12-01 08:26:00，这段区间内 45,046 行中多余重复 22,844 行（50.71%）；区间外重复率仅 1.12%。
12. **周六几乎没有交易**：只有 1 个周六有记录（2009-12-05），共 402 行；周日有 139,256 行。
13. **商品代码不规范**：原始唯一值 5,305 个，去空格并统一大写后 5,131 个；173 个小写后缀代码中 172 个同时存在大写版本；1,210 个代码对应多于 1 种描述。
14. **非数字代码不全是非商品**：6,093 行（0.57%）的 StockCode 不是"数字 + 可选字母"格式，但其中 262 行的描述是具体商品。
15. **一个客户号对应多个国家**：13 个客户；**一张发票多个时间戳**：83 张，最大跨度 0 days 00:09:00。
16. **最后一个月不完整**：数据止于 2011-12-09 12:50:00，2011-12 只有 25,526 行。
17. **国家字段含非国家值**：`Unspecified` 756 行，`European Community` 61 行。
